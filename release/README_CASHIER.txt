================================================================
ZEEDAT POS - CASHIER DESKTOP APP INSTRUCTIONS
================================================================

1. HOW TO RUN:
   Double-click "Zeedat POS.exe" to launch the POS.

2. CONNECTING TO CLOUD / SERVER:
   Open "config.json" in Notepad and change "server_url" to your
   server address (for example: "https://your-cloud-url.com").

3. OFFLINE CAPABILITY:
   - Does NOT require XAMPP or MySQL on this cashier PC.
   - If internet disconnects, billing and barcode scanning
     continue normally.
   - When internet reconnects, sales automatically sync!
